# 일본 쇼츠 소재 찾기 🇯🇵

일본 타깃 유튜브 쇼츠 소재를 찾는 개인용 도구예요.
**구독자 대비 조회수 배수(outlier)** 와 **시간당 조회수**로 "작은 채널인데 터진 영상"을 찾아줍니다.

> 현재 진행 상황: ✅ 1단계 트렌드 · ✅ 2단계 급상승 · ✅ 3단계 일본판 확인 · ⬜ 4단계 화면

---

## 0. 처음 한 번만: 준비하기

### ① 파이썬 설치 확인
터미널(윈도우는 **명령 프롬프트** 또는 **PowerShell**, 맥은 **터미널** 앱)을 열고 입력하세요.

```bash
python --version
```

`Python 3.10` 이상이 나오면 OK. 안 나오면 https://www.python.org/downloads/ 에서 설치하세요.
(윈도우는 설치 화면 첫 페이지의 **"Add Python to PATH"** 체크박스를 꼭 체크!)

> 맥에서 `python`이 안 되면 이 문서의 모든 `python`을 `python3`로, `pip`을 `pip3`로 바꿔서 입력하세요.

### ② 이 폴더로 이동

```bash
cd 이_폴더의_경로
```

팁: `cd ` (cd 뒤에 한 칸 띄우고)까지 입력한 뒤, 폴더를 터미널 창으로 끌어다 놓으면 경로가 자동으로 입력돼요.

### ③ 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

## 3. 사용법

### 🔥 트렌드: 최근 일본 인기 쇼츠 찾기

```bash
python jp_shorts_finder.py trend --keywords 神回 ドッキリ --days 7
```

결과 예시:
```
배수          조회수     시간당  제목
x100.0     500,000회  10,416/h  猫が逆さまに歩く  https://youtube.com/shorts/...
x2.0     2,000,000회 199,995/h  【神回】ドッキリ大成功  https://youtube.com/shorts/...

저장: .../output/trend_20260929_1408.csv
오늘 할당량: 202 / 10,000 유닛 사용 (남음 9,798) · 이번 실행: API 4회(202유닛), 캐시 2회
```

- **배수(x100.0)**: 구독자 수의 100배 조회수. 높을수록 "채널 힘이 아니라 소재 힘"으로 뜬 영상이에요.
  구독자 수를 숨긴 채널은 `x-`로 나와요.
- **시간당**: 올라온 뒤 1시간에 평균 몇 회 조회됐는지. 높을수록 지금 빠르게 뜨는 중이에요.
- 결과는 `output/` 폴더에 CSV(엑셀로 열림)로도 저장돼요.

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--keywords` | 검색할 일본어 키워드 (여러 개 가능, 띄어쓰기로 구분) | バラエティ 神回 切り抜き |
| `--days` | 최근 며칠 동안 올라온 영상 | 7 |
| `--min-views` | 이 조회수보다 적으면 제외 | 100000 |
| `--top` | 화면에 보여줄 개수 | 30 |
| `--pages` | 키워드당 검색 페이지 수 (1페이지 = 50개 = 100유닛) | 1 |
| `--refresh` | 캐시 무시하고 새로 검색 | 꺼짐 |

키워드에 띄어쓰기가 있으면 따옴표로 묶으세요: `--keywords "ケチャップ 逆さま" 神回`

### 🌏 해외에서 터진 쇼츠·롱폼 → 일본에 있을까? (무료)

**① 한국·미국·영국에서 조회수가 터진 쇼츠·롱폼 모으기**

롱폼은 편집해서 쇼츠로 만들 수 있으니 기본으로 같이 보여줘요.
**뮤직비디오는 저작권 때문에 편집·재업로드가 어려워서 기본으로 빼요** (`--include-music`을 붙이면 포함).
**쇼츠**는 3분 이하 + 세로 영상만이에요. 3분 이하라도 가로 영상(예고편 등)은 `롱폼`으로 표시돼요.

```bash
python jp_shorts_finder.py overseas
```

결과 예시:
```
해외에서 터진 영상 41개 (쇼츠 18 · 롱폼 23, 조회수 순)

 1. [US·롱폼 14:32]  12,345,678회 · 85,000/h · x3.1    I Survived 100 Days…
    영상: https://youtube.com/watch?v=...
    번역: https://translate.google.com/?...   ← Ctrl+클릭하면 제목이 일본어로 번역돼요
 2. [KR·쇼츠]   8,765,432회 · 60,000/h · x120.5  케첩 거꾸로 짜기…
    영상: https://youtube.com/shorts/...
```

- `[KR]`/`[US]`/`[GB]`: 채널이 설정한 국가예요. 국가를 설정하지 않은 채널은 검색한 지역으로 표시돼요.
  일본 채널 영상은 빠져요.
- **번역** 링크를 누르면 구글 번역에서 제목이 일본어로 바뀌어 나와요. ②의 검색어를 만들 때 참고하세요.
- 결과는 `output/overseas_날짜.csv`로도 저장돼요 (엑셀로 열기).

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--type` | `all` 쇼츠+롱폼 / `shorts` 쇼츠만 / `long` 롱폼만 | all |
| `--regions` | 볼 나라 (`KR` 한국, `US` 미국, `GB` 영국) | 셋 다 |
| `--days` | 최근 며칠 안에 올라온 영상 | 7 |
| `--min-views` | 이 조회수보다 적으면 제외 | 500000 |
| `--sort` | 정렬: `views` 조회수 / `vph` 시간당 조회수 / `outlier` 구독자 대비 배수 | views |
| `--keywords` | 특정 분야만 검색 (예: `--keywords "life hack" prank`) | 없음 (`#shorts`로 검색) |
| `--no-search` | 검색 없이 나라별 인기 차트만 (가장 저렴) | 꺼짐 |
| `--include-music` | 뮤직비디오도 포함 | 꺼짐 (제외) |

- **롱폼**은 나라별 인기 급상승 차트에서 가져와요 (나라당 약 15유닛, 매우 저렴).
  **쇼츠**는 차트 + `#shorts` 검색(나라당 100유닛)으로 가져와요.
- 할당량: 3개국 기본 실행 시 약 **350유닛**. `--type long`이면 약 45유닛.
  `--keywords`를 주면 키워드마다 나라당 100유닛 (쇼츠·롱폼을 같이 검색).
- 같은 조건으로 12시간 안에 다시 실행하면 캐시를 써서 거의 0유닛이에요.

**② 마음에 드는 영상이 일본에 있는지 확인**

1. 목록에서 영상을 고르고 **번역** 링크를 Ctrl+클릭 → 제목이 일본어로 번역돼요.
2. 번역된 일본어에서 **소재의 핵심 단어 2~3개**를 골라요.
3. 그 단어를 `--keywords` 뒤 따옴표 안에 넣어요.

예) `Five Nights At Freddy's Joins Fortnitemares 2026` → 핵심 단어: フォートナイト, フレディ

```bash
python jp_shorts_finder.py check --keywords "フォートナイト フレディ" --type all
```

⚠️ 검색어는 반드시 **일본어**로 넣으세요. 한국어가 들어 있으면 할당량을 쓰기 전에 멈추고 알려줘요.

### 🔎 체크: 이 소재로 일본 쇼츠가 이미 있을까? (무료, Claude 키 필요 없음)

일본어 검색어를 **직접** 넣어서 확인해요. 한국어 소재는 파파고·구글 번역으로 일본어 단어 2~3개로 바꿔서 넣으세요.

```bash
python jp_shorts_finder.py check --keywords "ドッキリ リアクション"
```

결과 예시:
```
🟡 [차별화 필요] 같은 소재 일본 쇼츠 3개, 그중 100,000회 이상 1개 → 몇 개 떴으니 각도·편집을 다르게

✅ 같은 소재로 본 영상 (3개)
     850,000회  ドッキリのリアクションが…  https://youtube.com/shorts/...
✖ 제외한 영상 중 조회수 상위 (전체 41개) — 같은 소재인데 빠졌다면 검색어를 바꿔 보세요
   1,200,000회  …  https://youtube.com/shorts/...
```

- **같은 소재 판단 방법**: 검색 결과 중 **제목에 검색어가 모두 들어간 영상**만 같은 소재로 세요.
  판정 기준은 아래 '일본판 확인'과 같아요 (10만회 이상 성공작 0개 → 🟢, 1~2개 → 🟡, 3개 이상 → 🔴).
- **한계**: 같은 소재여도 제목에 다른 단어를 쓰면 빠져요 (→ 실제보다 🟢 쪽으로 나올 수 있음).
  **✖ 제외한 영상** 목록을 훑어보고, 같은 소재가 보이면 검색어를 바꿔 한 번 더 해보세요.
  검색어가 하나면 너무 넓고, 4개 이상이면 너무 좁아요. **2~3개**가 적당해요.
- 1회에 약 102유닛. 같은 검색어는 12시간 동안 캐시돼요.
- 옵션: `--hit-views`(성공작 기준 조회수, 기본 100000), `--days`(최근 며칠, 기본 365), `--show`(목록 개수, 기본 5)
- `--type all`: 일본 **롱폼**까지 같이 찾아요. 해외 롱폼 소재가 일본에 롱폼으로 이미 들어왔는지 볼 때 쓰세요.
  (기본은 쇼츠만. 비용은 같아요)

### 🚀 급상승: 요즘 조회수가 빠르게 오르는 영상 찾기

`trend`로 모은 영상들의 조회수를 **몇 시간마다 기록**해두고, 그사이 얼마나 올랐는지 비교해요.

**① 영상 모으기** — `trend`를 실행하면 모은 영상이 자동으로 추적 목록에 들어가요 (첫 기록도 이때 저장).

```bash
python jp_shorts_finder.py trend --keywords バラエティ 神回 ドッキリ
```

**② 조회수 기록하기** — 1시간 이상 지난 뒤 실행하세요. 50개당 **1유닛**이라 거의 공짜예요.

```bash
python jp_shorts_finder.py snapshot
```

**③ 급상승 보기** (할당량 안 씀)

```bash
python jp_shorts_finder.py rising --hours 24
```

결과 예시:
```
  시간당 증가       증가량   증가율   기간    현재 조회수  제목
  +99,998/h   +400,000회  +80.0%   4.0h   900,000회  猫が逆さまに歩く  https://...
```

- **시간당 증가**: 이 순서로 정렬돼요. 지금 가장 빠르게 크는 영상이 위에 와요.
- **기간**: 비교한 두 기록 사이의 시간. 기록을 시작한 지 24시간이 안 됐으면 24보다 짧게 나와요.
- **증가율**: 기준 시점 조회수 대비 몇 % 올랐는지. 작은 영상이 폭발하는 걸 찾을 때 좋아요.

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--hours` | 최근 몇 시간 동안의 증가량을 볼지 | 24 |
| `--min-gain` | 이만큼도 안 오른 영상은 제외 | 0 |
| `--top` | 화면에 보여줄 개수 | 30 |
| `--max-age` (snapshot) | 최근 며칠 안에 올라온 영상만 기록 | 14 |

**④ 자동 기록 켜기 (추천)** — 매번 `snapshot`을 직접 치지 않아도 되게 윈도우 작업 스케줄러에 등록해요.

```bash
python jp_shorts_finder.py schedule --every 3
```

- 3시간마다 자동으로 조회수를 기록해요 (영상 500개 기준 하루 약 80유닛).
- **컴퓨터가 켜져 있고 로그인된 동안만** 실행돼요. 꺼져 있던 시간은 건너뛰어요.
- 실행할 때 검은 창이 잠깐 떴다 사라질 수 있어요. 정상이에요.
- 잘 되고 있는지는 `data\snapshot.log` 파일(메모장으로 열기)이나 `rising` 첫 줄의 "마지막 기록"으로 확인해요.
- 끄기: `python jp_shorts_finder.py unschedule`
- ⚠️ 폴더를 다른 곳으로 옮기면 `schedule`을 다시 한 번 실행하세요.
- 맥은 이 명령이 `crontab`에 붙여넣을 한 줄을 알려줘요.

### 🇯🇵 일본판 확인: 한국·미국에서 뜬 쇼츠, 일본에도 있을까? (Claude API 키 필요, 유료)

> 결제 없이 하려면 위의 `check`를 쓰세요. `jpcheck`는 번역과 "같은 소재" 판단을 Claude가 대신 해줘서 더 정확하고 편해요.

한국·미국 인기 쇼츠 제목을 **Claude가 일본어 검색어로 바꿔서** 일본 유튜브를 검색하고,
검색 결과 중 **정말 같은 소재인 영상만 Claude가 골라낸 뒤** 판정해요.

```bash
# 한국 인기 차트에서 쇼츠 5개 골라 확인
python jp_shorts_finder.py jpcheck --region KR --limit 5

# 미국에서 키워드로 찾은 쇼츠 확인
python jp_shorts_finder.py jpcheck --region US --keywords "life hack" --limit 5

# 내가 생각한 소재를 직접 확인 (여러 개는 따옴표로 각각 묶기)
python jp_shorts_finder.py jpcheck --title "케첩 거꾸로 짜기 챌린지" "편의점 신상 조합 먹방"
```

결과 예시:
```
🟢 [선점 가능] 케첩 거꾸로 짜기 챌린지
    소재: 케첩을 거꾸로 짜는 실험  |  일본 검색어: ケチャップ 逆さま 実験
    같은 소재 일본 쇼츠 1개, 그중 100,000회 이상 0개 → 아직 일본에서 뜬 영상이 없음
```

**판정 기준** (같은 소재 일본 쇼츠 중 조회수 10만 이상인 "성공작" 개수)

| 판정 | 기준 | 의미 |
|---|---|---|
| 🟢 선점 가능 | 성공작 0개 | 일본에서 아직 아무도 성공 못 함 → 먼저 만들 기회 |
| 🟡 차별화 필요 | 성공작 1~2개 | 이미 뜬 게 있으니 각도·편집을 다르게 |
| 🔴 포화 | 성공작 3개 이상 | 이미 여러 개가 성공함 |

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--region` | 어느 나라에서 뜬 쇼츠를 볼지 (`KR` 또는 `US`) | KR |
| `--keywords` | 그 나라에서 이 키워드로 검색 (없으면 인기 차트 사용) | 없음 |
| `--title` | 확인할 제목을 직접 입력 | 없음 |
| `--limit` | 확인할 개수 | 5 |
| `--hit-views` | 이 조회수 이상이면 "성공작"으로 봄 | 100000 |
| `--jp-days` | 일본에서 최근 며칠 안의 영상과 비교 | 365 |

**비용**
- YouTube: 1개 확인할 때마다 일본 검색 **약 102유닛** → `--limit 5`면 약 520유닛. 실행 전에 예상량을 보여주고, 부족하면 멈춰요.
- Claude: 5개 확인에 대략 **100~200원** 수준 (Claude Opus 5.5 사용). 같은 제목을 다시 확인하면 저장해둔 답을 써서 **0원**이에요.
- 인기 차트(`--keywords` 없이)는 원본을 모으는 데 몇 유닛밖에 안 들어서 가장 저렴해요.
- 한국 인기 차트에 쇼츠가 적을 때는 `--keywords`를 쓰세요.

#### Claude API 키 발급

1. https://console.anthropic.com/ 가입 → 로그인
2. **Billing**에서 크레딧 충전 (최소 금액이면 충분해요)
3. **API Keys** → **Create Key** → 나온 키(`sk-ant-...`) 복사
4. `.env` 파일의 `ANTHROPIC_API_KEY=` 뒤에 붙여넣고 저장

   PowerShell에서 한 줄 추가하기:
   ```powershell
   Add-Content .env "ANTHROPIC_API_KEY=복사한키"
   ```

## 할당량 아끼는 원리

YouTube API는 하루 **10,000유닛** 무료예요.

| 동작 | 비용 |
|---|---|
| 검색 1회 (50개) | 100유닛 |
| 영상 정보 조회 (50개 묶음) | 1유닛 |
| 채널 구독자 조회 (50개 묶음) | 1유닛 |

→ 키워드 1개 트렌드 검색 ≈ **102유닛**. 하루에 키워드 검색을 약 **95번** 할 수 있어요.

- **캐시**: 같은 검색은 **12시간**, 조회수·구독자 정보는 **1시간** 동안 저장해두고 다시 써요.
  이때는 할당량이 **0**이에요. 최신 결과가 꼭 필요할 때만 `--refresh`를 붙이세요.
- **안전장치**: 남은 할당량이 부족하면 API를 부르기 전에 멈춰요.
- **초기화 시간**: 태평양 시간 자정 = **한국 시간 오후 4시**(여름) / **오후 5시**(겨울).
- 사용 기록은 이 도구가 부른 것만 세요. 같은 키를 다른 곳에서도 쓰면 실제로 남은 양은 더 적을 수 있어요.

## 자주 나오는 오류

| 메시지 | 해결 |
|---|---|
| `.env 파일에 YT_API_KEY가 없어요` | 2번 단계를 다시 확인. 파일 이름이 `.env.txt`가 아닌지도 확인 (윈도우는 확장자가 숨겨져 있을 수 있어요) |
| `YT_API_KEY가 올바르지 않아요` | 키를 다시 복사해서 붙여넣기 |

| `할당량을 모두 썼어요` | 한국 시간 오후 4~5시 이후에 다시 실행 |
| `No module named ...` | `pip install -r requirements.txt` 다시 실행 |
| `ANTHROPIC_API_KEY가 없어요` / `올바르지 않아요` | 위의 'Claude API 키 발급' 확인 |
| `크레딧이 부족해요` | console.anthropic.com → Billing에서 충전 |
