# 일본 쇼츠 소재 찾기 🇯🇵

일본 타깃 유튜브 쇼츠 소재를 찾는 개인용 도구예요.
**구독자 대비 조회수 배수(outlier)** 와 **시간당 조회수**로 "작은 채널인데 터진 영상"을 찾아줍니다.

> 현재 진행 상황: ✅ 1단계 트렌드 · ⬜ 2단계 급상승 · ⬜ 3단계 일본판 확인 · ⬜ 4단계 화면

---

## 0. 처음 한 번만: 준비하기

### ① 파이썬 설치 확인
터미널(윈도우는 **명령 프롬프트** 또는 **PowerShell**, 맥은 **터미널** 앱)을 열고 입력하세요.

```bash
python --version
```

`Python 3.9` 이상이 나오면 OK. 안 나오면 https://www.python.org/downloads/ 에서 설치하세요.
(윈도우는 설치 화면 첫 페이지의 **"Add Python to PATH"** 체크박스를 꼭 체크!)

> 맥에서 `python`이 안 되면 이 문서의 모든 `python`을 `python3`로, `pip`을 `pip3`로 바꿔서 입력하세요.

### ② 이 폴더로 이동

```bash
cd 이_폴더의_경로
```

팁: `cd ` (cd 뒤에 한 칸 띄우고)까지 입력한 뒤, 폴더를 터미널 창으로 끌어다 놓으면 경로가 자동으로 입력돼요.

### ③ 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

## 1. YouTube API 키 발급 (무료)

1. https://console.cloud.google.com/ 접속 → 구글 로그인
2. 상단의 프로젝트 선택 → **새 프로젝트** 만들기 (이름 아무거나)
3. 검색창에 **YouTube Data API v3** 검색 → **사용(Enable)** 클릭
4. 왼쪽 메뉴 **API 및 서비스 → 사용자 인증 정보** → **+ 사용자 인증 정보 만들기 → API 키**
5. 나온 키(`AIza...`로 시작)를 복사

## 2. API 키 넣기 (.env 파일)

1. 폴더에 있는 `.env.example` 파일을 복사해서 이름을 **`.env`** 로 바꾸세요.
   - 윈도우: `copy .env.example .env`
   - 맥: `cp .env.example .env`
2. `.env`를 메모장(맥은 텍스트 편집기)으로 열고 `=` 뒤에 키를 붙여넣고 저장하세요.

```
YT_API_KEY=AIzaSy여기에_복사한_키
ANTHROPIC_API_KEY=
```

- 따옴표나 띄어쓰기 없이 붙여넣으세요.
- `ANTHROPIC_API_KEY`는 3단계에서 쓸 거라 지금은 비워둬도 돼요.
- `.env`는 `.gitignore`에 들어 있어서 GitHub에 올라가지 않아요.

## 3. 사용법

### 🔥 트렌드: 최근 일본 인기 쇼츠 찾기

```bash
python jp_shorts_finder.py trend --keywords 神回 ドッキリ --days 7
```

결과 예시:
```
배수          조회수     시간당  제목
x100.0     500,000회  10,416/h  猫が逆さまに歩く  https://youtube.com/shorts/...
x2.0     2,000,000회 199,995/h  【神回】ドッキリ大成功  https://youtube.com/shorts/...

저장: .../output/trend_20260929_1408.csv
오늘 할당량: 202 / 10,000 유닛 사용 (남음 9,798) · 이번 실행: API 4회(202유닛), 캐시 2회
```

- **배수(x100.0)**: 구독자 수의 100배 조회수. 높을수록 "채널 힘이 아니라 소재 힘"으로 뜬 영상이에요.
  구독자 수를 숨긴 채널은 `x-`로 나와요.
- **시간당**: 올라온 뒤 1시간에 평균 몇 회 조회됐는지. 높을수록 지금 빠르게 뜨는 중이에요.
- 결과는 `output/` 폴더에 CSV(엑셀로 열림)로도 저장돼요.

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--keywords` | 검색할 일본어 키워드 (여러 개 가능, 띄어쓰기로 구분) | バラエティ 神回 切り抜き |
| `--days` | 최근 며칠 동안 올라온 영상 | 7 |
| `--min-views` | 이 조회수보다 적으면 제외 | 100000 |
| `--top` | 화면에 보여줄 개수 | 30 |
| `--pages` | 키워드당 검색 페이지 수 (1페이지 = 50개 = 100유닛) | 1 |
| `--refresh` | 캐시 무시하고 새로 검색 | 꺼짐 |

키워드에 띄어쓰기가 있으면 따옴표로 묶으세요: `--keywords "ケチャップ 逆さま" 神回`

### 🔎 체크: 이 소재로 일본 쇼츠가 이미 있을까?

```bash
python jp_shorts_finder.py check --keywords "ケチャップ 逆さま"
```

## 할당량 아끼는 원리

YouTube API는 하루 **10,000유닛** 무료예요.

| 동작 | 비용 |
|---|---|
| 검색 1회 (50개) | 100유닛 |
| 영상 정보 조회 (50개 묶음) | 1유닛 |
| 채널 구독자 조회 (50개 묶음) | 1유닛 |

→ 키워드 1개 트렌드 검색 ≈ **102유닛**. 하루에 키워드 검색을 약 **95번** 할 수 있어요.

- **캐시**: 같은 검색은 **12시간**, 조회수·구독자 정보는 **1시간** 동안 저장해두고 다시 써요.
  이때는 할당량이 **0**이에요. 최신 결과가 꼭 필요할 때만 `--refresh`를 붙이세요.
- **안전장치**: 남은 할당량이 부족하면 API를 부르기 전에 멈춰요.
- **초기화 시간**: 태평양 시간 자정 = **한국 시간 오후 4시**(여름) / **오후 5시**(겨울).
- 사용 기록은 이 도구가 부른 것만 세요. 같은 키를 다른 곳에서도 쓰면 실제로 남은 양은 더 적을 수 있어요.

## 자주 나오는 오류

| 메시지 | 해결 |
|---|---|
| `.env 파일에 YT_API_KEY가 없어요` | 2번 단계를 다시 확인. 파일 이름이 `.env.txt`가 아닌지도 확인 (윈도우는 확장자가 숨겨져 있을 수 있어요) |
| `YT_API_KEY가 올바르지 않아요` | 키를 다시 복사해서 붙여넣기 |
| `YouTube Data API v3를 사용 설정해 주세요` | 1번의 3단계(Enable)를 확인 |
| `할당량을 모두 썼어요` | 한국 시간 오후 4~5시 이후에 다시 실행 |
| `No module named ...` | `pip install -r requirements.txt` 다시 실행 |

## 파일 구조

```
jp_shorts_finder.py   ← 실행하는 파일
shorts/               ← 내부 코드 (config, db, youtube, metrics, trending)
tests/                ← 자동 테스트 (API 키 없이 가짜 데이터로 동작 확인)
data/shorts.db        ← 캐시·할당량·수집 영상 기록 (자동 생성)
output/               ← CSV 결과 (자동 생성)
```

테스트 실행: `python -m unittest discover tests -v`
